How It Works & Feature Walkthrough

STEP 1 OF 4 • CORE ENGINE
Real-Time Typing Engine
How Inline detects and fixes typos across every macOS application in under a millisecond:
Sub-Millisecond Hardware Hook
Intercepts keystrokes at the macOS CGEventTap layer in under 2 microseconds with ~0% idle CPU and under 120 MB RAM.
Space Evaluates • Enter Never Autocorrects
Pressing Space evaluates the word you just typed. Pressing Enter / Return commits your exact raw text untouched so terminal commands and code never get corrupted.
Single-Key Undo on Backspace
Didn't want a correction? Press Backspace once right after any replacement to revert to your exact original letters and temporarily suppress re-correction.
Context-Aware Intelligence
Built for natural writing, fast messaging, and software engineering:
240,000+ Contextual Bigrams
Uses the preceding word to disambiguate typos accurately — for example, helo becomes help after "need", but hello after "say".
Run-Together Word Splitting & Capitalization
Automatically splits accidentally joined words (whenI → when I, twowords → two words) and capitalizes sentence starts.
Slang & Developer Whitelist
Protects 180+ chat acronyms (gng, brb, idk, ngl, tbh) and developer terms (repo, pr, cli, sdk, api, async).
On-Device Privacy & Controls
Everything stays strictly on your Mac with instant control from the window or menu bar:
100% Local & Zero Network Activity
No cloud calls or telemetry. Secure password inputs are ignored automatically, and the volatile word buffer purges after 30 seconds of inactivity.
System Settings Window & Menu Bar Control
Opens immediately when launched so you can test corrections in the live Playground, exclude specific apps, or add custom vocabulary. Also accessible via the |▪ menu bar icon or Cmd+Opt+Shift+K.
Custom Vocabulary & App Exclusions
Add project-specific jargon to the ignore list or pause Inline automatically inside specific IDEs and terminals.
macOS Permissions & Quick Setup
How first-launch permissions work on macOS 12+:
1. Input Monitoring
Allows Inline to detect word boundaries locally as you type. Click Open Settings in the setup walkthrough and toggle Inline ON.
2. Accessibility
Allows Inline to send backspaces and replacement text into active text fields. Toggle Inline ON in System Settings → Privacy & Security → Accessibility.
3. Automatic Live Detection
Once both switches are toggled ON in macOS System Settings, Inline automatically attaches its keyboard hook and opens the Settings window.

Features Summary

  • Sub-Millisecond Speed
    Intercepts hardware events in under 2 microseconds via CGEventTap. Typo lookups complete in <100 µs with ~0% idle CPU and minimal RAM usage.
  • Single-Key Undo on Backspace
    If a word is autocorrected and you want your raw typed input back, press Backspace once. Inline reverts the correction immediately.
  • Context-Aware Bigrams
    Disambiguates words against conversational context using a 240,000+ bigram corpus (e.g. "helo" becomes "help" after "need", but "hello" after "say").
  • Run-Together Word Splitting
    Automatically detects and splits fused words when a space is accidentally skipped (e.g. theclass → the class).
  • Enter Never Autocorrects
    Pressing Return or Enter commits your exact raw input untouched, keeping code, commands, and short lines intact.
  • Strict Local Privacy
    100% on-device operation with zero network activity. Memory buffer auto-purges after 30 seconds of typing inactivity, and password fields are strictly ignored.
  • Slang & Developer Whitelist
    Protected vocabulary for 180+ internet acronyms (gng, brb, idk, ngl, tbh) and developer keywords (repo, pr, cli, sdk, api, async).

Architecture

1. Intercept
CGEventTap
Low-latency event tap on macOS HID stream
2. Filter
Loopback Filter
Rejects self-generated synthetic keystrokes
3. Buffer
Ephemeral Buffer
Volatile memory; auto-purges after 30 seconds
4. Evaluate
Tier 1 Engine
SymSpell unigram dictionary + bigrams
5. Replace
Atomic Inject
Sends backspaces and replacement string
