Engineering Deep Dive

How Inline Works Under the Hood

An in-depth breakdown of the 7-stage zero-latency pipeline processing every keystroke from OS tap to sub-pixel overlay.

Pipeline 1: Sub-Microsecond Keystroke Interception & Loopback Barrier
≤ 2 μs latency • Lock-Free Event Loop

Inline registers a low-latency hook at the OS session level via native macOS CGEventTap (kCGSessionEventTap, inserted via kCGHeadInsertEventTap) listening for kCGEventKeyDown. On Windows, WH_KEYBOARD_LL intercepts raw scan codes.

  • Synthetic Loopback Drop: Injected correction keystrokes carry a custom signature (kCGEventSourceUserData). The hook drops them instantly to prevent infinite recursion.
  • Execution Budget: Interception completes within 2 microseconds on a dedicated event thread without locks or heap allocations.
  • Enter Pass-Through: Enter / Return ( , ) clears the buffer and passes through untouched without triggering autocorrect.
// platform/mac/hook/mac_keyboard_hook.mm CGEventRef eventTapCallback(CGEventTapProxy proxy, CGEventType type, CGEventRef event, void* refcon) { int64_t sourceTag = CGEventGetIntegerValueField( event, kCGEventSourceUserData); if (sourceTag == INLINE_SYNTHETIC_TAG) { return event; // Bypass injected events } int64_t keyCode = CGEventGetIntegerValueField( event, kCGKeyboardEventKeycode); onRawKeyEvent(keyCode, flags); return event; // Non-blocking dispatch }
Pipeline 2: Security & Password Gating
0 Bytes on Disk • Ephemeral RAM Buffer

Before processing any keystroke, Inline queries the focused window's accessibility attributes (kAXRoleAttribute and kAXSubroleAttribute) to detect the exact nature of the active text field.

  • Password Gatekeeper: If an element is identified as AXSecureTextField, a credit card field, or PIN box, Inline enters a dormant state where all keystrokes pass unmodified with zero buffer tracking.
  • Inactivity Purge: Keystroke buffers are purged automatically after 30 seconds of typing inactivity.
  • Zero Telemetry: All evaluation is local in RAM; zero network sockets or disk log files are created.
// platform/mac/caret/secure_field_classifier.cpp bool isSecureFieldActive(AXUIElementRef focusedElem) { CFTypeRef role = nullptr; if (AXUIElementCopyAttributeValue(focusedElem, kAXSubroleAttribute, &role) == kAXErrorSuccess) { bool isSecure = CFEqual(role, kAXSecureTextFieldSubrole); CFRelease(role); if (isSecure) return true; // Dormant bypass } return false; }
Pipeline 3: Universal Multi-Tier Caret Localization
Sub-Pixel Accuracy • Chromium Blink Sync

To place predictions beside the blinking cursor in native macOS apps, Chromium browsers, and Electron text fields, Inline implements a 4-tier Accessibility (AX) ladder with sub-pixel localization.

  • effectiveLoc Ladder: Resolves Chromium's asynchronous selection lag in Google search, YouTube, and web text areas using an end-of-text range ladder.
  • Baseline Centering: Centers the vertical baseline automatically on single-line search bars to prevent microscopic floating overlays.
  • Forward Monotonicity: Locks horizontal progression so suggestions stay locked strictly to the right of the insertion bar during fast typing.
// platform/mac/caret/mac_caret_tracker.mm CaretGeometry resolveCaretPosition(AXUIElementRef elem) { AXValueRef rangeVal; if (AXUIElementCopyAttributeValue(elem, kAXSelectedTextRangeAttribute, (CFTypeRef*)&rangeVal) == kAXErrorSuccess) { CFRange range; AXValueGetValue(rangeVal, kAXValueCFRangeType, &range); // Probes AXBoundsForRange with coordinate flip return computeSubPixelBounds(elem, range); } return CaretGeometry::invalid(); }
Pipeline 4: Tier 1 SymSpell Autocorrect & Language Modeling
< 40 μs lookup • 82K Unigrams • 243K Bigrams

When the user presses Space, Inline evaluates the active word buffer. The SymSpell Symmetric Delete algorithm queries an 82,765 unigram dictionary and 243,342 bigrams with Damerau-Levenshtein distance ≤ 2.

  • Context Disambiguation: Evaluates bigrams from the prior word to resolve homophones (e.g. there vs their).
  • Run-Together Word Splitting: Dynamic programming segments concatenated words (e.g. whenI → when I).
  • Protected Vocabulary: Preserves 180+ internet acronyms (gng, idk, tbh) and developer terms (repo, pr, cli, sdk).
// core/tier1/corrector.cpp CorrectionResult correctWord(const std::wstring& word, const SymSpellDict& dict, const AppConfig& cfg, bool isSentenceStart, const std::wstring& prevWord) { if (dict.isProtected(word)) return {false, word}; auto suggestions = dict.lookup(word, 2); auto best = rankByBigramContext(suggestions, prevWord); return {true, best.term}; }
Pipeline 5: Single-Key Undo State Machine
Atomic Revert • Zero Cursor Drift

Inline tracks recent substitutions in a deterministic state machine. If an autocorrection or ghost suggestion is applied and the user presses Backspace immediately after, the substitution is reverted.

  • Exact Keystroke Restoration: Computes the common prefix length between the typo and the replacement, emitting the exact sequence of backspaces and original letters.
  • Zero Re-Correction Loops: Automatically marks reverted terms as rejected for that context, preventing recursive correction.
  • Immediate Hand-Off: Any subsequent keystrokes reset the state machine cleanly to normal typing mode.
// core/undo/undo_state_machine.cpp UndoAction onBackspacePressed() { if (state_ == State::EligibleForUndo) { state_ = State::Idle; return { .type = UndoAction::RevertCorrection, .revertedText = lastRawKeystrokes_, .correctedText = lastCorrectedText_ }; } return { .type = UndoAction::None }; }
Pipeline 6: Dual-Tier Predictive Engine (Beta)
Experimental Beta • Disabled by Default

Ghost Text predictive writing combines sub-millisecond n-gram trie lookups with an out-of-process SmolLM2-135M (Q8_0) neural model running locally over 2 CPU threads via llama.cpp.

  • Beta Notice: This feature is currently in beta testing, turned off by default (ghostTextEnabled = false), and may not work on all Mac hardware and macOS configurations.
  • One Word Mode: Option to autocomplete only the active word currently being typed at your cursor, avoiding multi-word sentences.
  • Token Healing: Heals split BPE tokens across word boundaries to prevent malformed word fragments.
// core/config/app_config.h struct AppConfig { bool masterEnabled = true; bool singleKeyUndoEnabled = true; bool splitRunTogetherWords = true; bool sentenceCorrectionEnabled = true; // Ghost Writer: Disabled by default (Beta) bool ghostTextEnabled = false; KeyCode acceptKey = KeyCode::Tab; };
Pipeline 7: Sub-Pixel Ghost Text Overlay
< 0.2 ms shift • Borderless NSPanel • Tab Swallow

When enabled, suggestions render in a borderless, click-through NSPanel aligned within ±0.5 pt of your host text box baseline.

  • advanceLayout: As the user types letters matching the prediction prefix, the overlay shifts rightward in < 0.2 ms on the main thread without re-querying the neural model.
  • Tab Key Swallow: Pressing Tab while ghost text is visible swallows the Tab event and types the suggestion. If no ghost text is visible, Tab passes straight through to the host app.
  • Smart Spacing: Preserves leading word-boundary spaces so completed words never collide.
// platform/mac/ghost/ghost_overlay.mm void GhostOverlay::advanceLayout(double charWidth, const std::wstring& rem) { NSRect frame = [panel_ frame]; frame.origin.x += charWidth; // Instant < 0.2ms shift [panel_ setFrame:frame display:YES]; [view_ updateRemainingText:rem]; }
