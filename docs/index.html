Works anywhere you work.

Every native macOS app, browser, terminal, and document editor. Zero extensions, zero plugins, zero cloud configurations.

Capabilities

Engineered for typing without interruption.

Ghost Writer Predictions

Inline renders soft gray continuations right next to your cursor. Accept with Tab, or keep typing to type right through the prediction without friction.

One Word Mode

Prefer focused completions? Enable One Word Mode to finish only the exact word you are currently typing on Tab, avoiding unwanted multi-word continuations.

Single-Key Undo

Never fight autocorrect again. If Inline corrects a word you intended to keep, a single press of Backspace instantly reverts it to your raw keystrokes.

Zero Cloud Dependencies

Everything runs on-device in isolated memory. No network traffic, no background telemetry, and no external daemons like Ollama required.

Slang & Jargon Whitelist

180+ modern chat acronyms (gng, idk, ngl, brb, ttyl) and developer terminology (repo, pr, cli, sdk, api, async) are protected from accidental alteration.

Private by Design

Zero internet access required. All predictions and corrections execute locally in-memory. Password fields and secure inputs are automatically suspended.
